# Homebrew Tap

Homebrew formulae for dean0x projects.

## Installation

```bash
brew tap dean0x/tap
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| [minotaur](Formula/minotaur.rb) | Secure AI agent sandbox wrapper using Podman rootless containers |

## Usage

```bash
# Install minotaur
brew install dean0x/tap/minotaur

# Or install directly without tapping first
brew install dean0x/tap/minotaur
```
